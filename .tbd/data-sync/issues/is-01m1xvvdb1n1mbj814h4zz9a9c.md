Deezer's Ethiopian catalogue is real. All six artists tested returned tracks with
working previews: Teddy Afro, Mahmoud Ahmed, Aster Aweke, Rophnan, Mulatu Astatke, Gigi.

This is the project's advantage over the retail box. A deck of Western hits makes the
game a memory test for whoever grew up with them; a deck split between global hits,
Ethiopian classics and Ethio-jazz makes it an actual contest.

- 80-120 cards for the first playable version
- Interleave global / Ethiopian / shared so neither player has home advantage
- Weight toward decades both players lived through
- Budget 1-2 min per card for year verification

Depends on the deck-builder CLI.
